# 08 Data and licenses

This page lists where every dataset and dependency comes from and the terms that apply, as understood when it was checked (Phase 0 and Phase 7). It is not
legal advice. Check the current terms before publishing or redistributing.

## Data in the repository

| Item | Where | Source and terms |
| --- | --- | --- |
| Print lookup tables (six, 33×33×33) | `data/lut_*.json` | Generated by `build/build_luts.py` from the six ICC profiles below using LittleCMS. Derived values (CMYK and printed Lab per grid node), not the profiles themselves. Each file records the profile's SHA-256. **Terms differ by owner: PRINTING United Alliance (three tables) gave written permission with a notice on 2026-10-01 (C5, closed); ECI (two tables) wrote on 2026-10-13 that derived tables need no permission while its profiles are not distributed, and that attribution would be appreciated (C22, closed; the email is kept privately by the maintainer); the FOGRA39 file's registry notice allows use and sharing (C23, closed)**. Notices: `NOTICE.md` and the page footer |
| Approved lexicon | `data/lexicon.json`, source in `lexicon/` | Written for this project. Cites papers by reference and reproduces no article text. Weights derive from published regression coefficients (Labrecque & Milne 2012), the Ou et al. 2004 model equations, and a re-analysis of the Jonauskaite et al. 2024 survey data |
| Emotion weights | `lexicon/emotion_weights.json` | Derived table only. The raw survey data (OSF project 873df, 7,387 participants) stays on the maintainer's machine and is git-ignored; the build re-checks the table against the paper when the file is present. Check the dataset's license on OSF before adding it to the repo |
| Test vectors | `engine/*_vectors.json` | Generated with colour-science (BSD-3-Clause) and the Sharma, Wu & Dalal (2005) published pairs |
| Third-party ASE sample | `engine/fixtures/third_party_sample.ase` | From the MIT-licensed `adobe-swatch-exchange` package's test files, used only to test the reader |
| Sample brand | `examples/fernhill-bakery/` | Fictional. The brand, colors and rationale notes are invented. **The spot-color names and Lab values are invented placeholders ("Sample Terracotta C"), not Pantone data** |

Installed by `npm ci` for tests only (TO-CONFIRM C41) |
| pdf-lib 1.17.1 | PDF spec sheet | MIT |
| esbuild 0.28.2 | Bundling | MIT |
| Development only: ase-util, markdown-it, postcss, playwright-core | Test readers and browser tests | MIT, MIT, MIT, Apache-2.0 |

| IBM Plex Sans and Plex Mono | Page fonts, loaded from Google Fonts; the page falls back to system fonts | SIL Open Font License 1.1 |

Licenses above are recorded from each package's published metadata and the notes made in Phase 0; re-check on upgrade (`npm ls` and `pip show`). The `apca-w3` licence makes keeping current a continuing duty: check `npm view apca-w3 version` before each release, and on a new release read its license and notes before upgrading (`engine/HANDOFF.md` has the routine). When `apca-w3` is upgraded, re-read what it imports: the replacement above covers only hex strings, and `engine/test_apcastub.mjs` will fail if the new version needs more.

This page is not legal advice. Whether the `apca-w3` license and the AGPL could be combined in one distribution was not settled; shipping without `colorparsley` avoids the question rather than answering it.
